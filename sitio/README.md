# Landing de Natural by Roberto Cuello

Copia de trabajo del export de Google AI Studio. Conserva React, TypeScript, Vite, Tailwind y el contenido original. El ZIP en la carpeta superior permanece intacto y la versión inicial está guardada en Git.

Consultar ../README.md, ../AGENTS.md y ../wiki/index.md para trabajar en este proyecto.

Desde la raíz, ./scripts/proyecto.ps1 ver inicia la vista local y ./scripts/proyecto.ps1 comprobar compila, revisa TypeScript y comprueba dependencias. La instalación usa pnpm con su archivo de bloqueo y las herramientas ya disponibles de Codex.

La landing actual no utiliza Gemini ni necesita una API key. .env.example es un ejemplo heredado sin credenciales reales. No copiar secretos al código del navegador.
